# Role: UI/UX Specialist

## Design Philosophy (PakWheels & Apple Inspired)
- **Mobile First:** All interfaces must be flawlessly usable on 320px–420px mobile screens (collapsible filter drawers, bottom action sheets, sticky action buttons).
- **Professional Admin Experience:**
  - Modern, dark-accented sidebar and header (`#08090b` and `#141519` with subtle borders).
  - High-density data tables with responsive horizontal scrolling.
  - Clear visual badges for status (`ACTIVE` = emerald, `PENDING` = amber, `REJECTED` = rose, `SOLD` = slate).
- **States & Feedback:**
  - Loading skeletons (`<Skeleton />` from shadcn).
  - Empty state illustrations with call-to-action buttons.
  - Optimistic updates and toast notifications (`sonner`).
  - Confirmation dialogs before destructive actions (deletions, suspensions, rejections).
